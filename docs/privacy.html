Hobble Creek Stake Broadcast Scheduler

Privacy Policy

Effective date: November 14, 2026

Purpose and use

Hobble Creek Stake Broadcast Scheduler is a private tool operated by the channel owner for personal use. It uses the YouTube Data API to schedule and manage live broadcasts for the configured YouTube channel.

Information accessed

When authorized, the scheduler can access YouTube channel information and the data needed to manage broadcasts, livestreams, and playlists. This can include channel, broadcast, stream, playlist, and video identifiers; event titles, descriptions, scheduled times, and visibility settings; and YouTube OAuth authorization tokens. When preparing a selected broadcast for the relay, it may retrieve that stream’s key and store it in an access-restricted file on the owner’s server. The relay uses the key to send video to YouTube; the key is replaced when another target is selected or removed by the owner.

How information is used and stored

The information is used only to create, inspect, update, select, and clean up the owner’s broadcasts and their configured playlist. OAuth tokens and any selected stream key are stored in access-restricted files on the owner’s broadcast server. Broadcast details are generally read from YouTube when needed rather than collected into a separate user database.

Sharing and retention

The scheduler does not sell or share Google user data with other people or companies. It sends the required broadcast and stream information to Google/YouTube when making API requests and sends the selected stream to YouTube for live delivery. Credentials remain on the owner’s server until removed or replaced. The owner can revoke the scheduler’s Google access at Google Account permissions and can remove locally stored credentials from the server.

Website visitors

This page is a static information page. The scheduler does not use it to collect personal information, set advertising cookies, or run analytics. GitHub hosts this page and may process technical request data under GitHub’s Privacy Statement.

Contact

For questions about this policy or the scheduler’s use of YouTube data, contact the support email listed on the scheduler’s Google authorization screen.
